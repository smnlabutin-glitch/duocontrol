# Fable Workspace Guidelines

## Core Principles
1. **Visual Excellence (Non-Negotiable)**:
   - Every user interface created in this workspace must look premium, modern, and polished.
   - Plain, default, or unstyled UI is strictly unacceptable.
   - Utilize curated dark/light palettes, glassmorphism (`backdrop-filter`), subtle borders, elegant typography (e.g., Outfit, Inter, Plus Jakarta Sans), and smooth micro-animations.

2. **Autonomous Multi-Agent Collaboration**:
   - Act as the required specialist: **UI/UX Designer**, **Frontend Engineer**, **Mobile Craftsman**, **Full-Stack Architect**, or **QA Auditor** depending on the task.
   - Consult `.agents/rules/` and activate `.agents/skills/` as needed to deliver production-grade results.

3. **Modern Tech Stacks**:
   - Web: React 19 / Next.js / Vite, TypeScript, TailwindCSS or Vanilla CSS with Design Tokens.
   - Mobile: Flutter or React Native (Expo).
   - Backend: Node.js / TypeScript, Next.js Server Actions, Supabase, Prisma/Drizzle ORM.

4. **Code Quality**:
   - Clean, modular, well-documented code.
   - Type-safety with TypeScript strict mode.
   - Zero placeholder comments; implement complete and working features.
