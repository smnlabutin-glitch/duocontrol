# 🚀 Fable: Пакет AI-Агентов и Скиллов для Разработки и Дизайна Приложений

В этот проект установлена и настроена полная экосистема специализированных AI-агентов, практических навыков (Skills) и архитектурных правил (Rules) для создания современных, визуально безупречных веб- и мобильных приложений.

Система оптимизирована для **Antigravity**, **Cursor**, **Claude Code** и **VS Code**.

---

## 👥 Ростер специализированных Агентов (Agent Roster)

| Агент | Специализация | Ключевые возможности |
| :--- | :--- | :--- |
| 🎨 **UI/UX Design Architect** | Премиальный дизайн и эстетика | Создание интерфейсов высшего уровня (Linear/Vercel/Apple style), современные цветовые палитры (HSL), типографика (Outfit, Inter, Plus Jakarta Sans), эффекты Glassmorphism, микроанимации и предотвращение «дешевого/шаблонного» вида ИИ. |
| ⚡ **Frontend Application Engineer** | Современный фронтенд | Архитектура компонентов (React, Next.js, Vite, TypeScript), оптимизация состояний (Zustand, React Query), модульная структура и адаптивная верстка. |
| 📱 **Mobile App Craftsman** | Мобильная разработка | Кроссплатформенные приложения на Flutter и React Native (Expo), плавная анимация 60/120fps, эргономика «зоны большого пальца» и Safe Area. |
| 🛠️ **Full-Stack & API Architect** | Бэкенд и базы данных | Проектирование REST/GraphQL/tRPC API, схемы БД (PostgreSQL, Supabase, Prisma/Drizzle), валидация Zod, безопасность и авторизация. |
| 🛡️ **QA, Performance & Security Auditor** | Контроль качества и скорости | Доступность WCAG 2.1 AA, Core Web Vitals (LCP < 2.5s), тесты (Vitest, Playwright), аудит безопасности и устранение багов. |
| 📉 **Ponytail & Token Saver** | Экономия токенов и минимализм кода | ~54% меньше кода (The Ladder, YAGNI, стандартная библиотека и нативные возможности платформы вместо лишних библиотек), сжатые технические ответы без «воды» (Caveman-стиль). |

## 💡 Примеры вызова агентов в чате

Вы можете обращаться напрямую к конкретной роли:

### 1. Экономия токенов и минимализм (Ponytail + Caveman):
> *"Выступи в роли **Ponytail Token Saver**: напиши функцию кеширования запросов самым простым и минимальным способом, без лишних пакетов и бойлерплейта, и ответь кратко."*

### 2. Запрос к Дизайнеру (UI/UX Architect):
> *"Выступи в роли **UI/UX Design Architect**: спроектируй дашборд для SaaS-сервиса с темной темой, неоновыми фиолетовыми акцентами, размытием стекла (glassmorphism) и плавными анимациями карточек."*

### 3. Запрос к Фронтенд-инженеру (Frontend Engineer):
> *"Выступи в роли **Frontend Application Engineer**: инициализируй проект на Vite + React + TypeScript + Tailwind и создай многофункциональный компонент модального окна с подтверждением действий."*

### 4. Запрос к Мобильному разработчику (Mobile Craftsman):
> *"Выступи в роли **Mobile App Craftsman**: напиши экран профиля на Flutter с красивым анимированным SliverAppBar и выдвижным нижним меню (bottom sheet)."*

### 5. Запрос к Бэкенд-архитектору (Full-Stack Architect):
> *"Выступи в роли **Full-Stack & API Architect**: спроектируй схему базы данных Prisma и Zod-валидаторы для системы подписок и оплаты."*

### 6. Запрос к QA-аудитору (QA & Security Auditor):
> *"Выступи в роли **QA Auditor**: проверь написанный компонент на соответствие стандартам доступности (WCAG 2.1 AA) и найди возможные утечки памяти."*
